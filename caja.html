Para comenzar el día debes abrir el turno: contar el efectivo inicial y el inventario. Hasta que abras la caja no podrás registrar ventas ni el cierre.

Datos del cierre

Solo productos “Otros” (sin sesiones ni membresías). Es el monto del sobre/minita.
🔒 Tarjeta, SINPE y Transferencia se cargan solo desde el Informe de Ventas (no se editan a mano).

📦 Mi conteo de apertura

Lo que contaste al abrir el turno. Se marca si NO coincide con el sistema (sin mostrar la cantidad real).

🧃 Desglose de Otros (minita)

Categorías de productos vendidos (Aguas, Energéticos, Galletas…). Los subtotales suman la minita.

🔷 Reporte SINPE del día

Cargue el Reporte SINPE (obligatorio para el cierre final). Cada referencia se registra una sola vez; el saldo pendiente por facturar se arrastra al siguiente cierre, así que no importa si un SINPE se factura otro día o si el reporte se sube en el parcial.

📸 Foto del datáfono

Obligatoria para cerrar (parcial: auditoría del datáfono · final: cierre de lote). Se sube y la IA lee el total para compararlo con Total Tarjeta.
